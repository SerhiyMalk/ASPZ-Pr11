# Практична робота №11: Багатопотоковість та синхронна обробка сигналів

Цей репозиторій містить рішення індивідуального завдання з системного програмування під Linux мовою C. Програма демонструє модель синхронної обробки сигналів у багатопотоковому середовищі за допомогою системного виклику `sigwaitinfo()`.

## Індивідуальне завдання (Варіант 11)
**Завдання:** Створити додаток, де кожен потік відповідає за свій набір сигналів і використовує `sigwaitinfo` для синхронної обробки.

## Теоретичне обґрунтування
Класичні обробники сигналів (signal handlers) є асинхронними, що створює ризики виникнення умов гонки (race conditions) при роботі з купою (heap) або спільними ресурсами в багатопотокових додатках. 

Для вирішення цієї проблеми в даній програмі застосовано синхронний підхід:
1. За допомогою `pthread_sigmask(SIG_BLOCK, ...)` у головному потоці повністю заблоковано асинхронну доставку сигналів `SIGINT` та `SIGTERM`. Усі дочірні потоки успадковують цю маску.
2. Створено два незалежні робочі потоки.
3. Кожен потік визначає власну маску інтересів і викликає `sigwaitinfo()`. Цей системний виклик переводить потік у стан очікування та атомарно витягує сигнал із черги очікування (pending signals) як звичайну синхронну подію. Це дозволяє безпечно аналізувати метадані сигналу (структуру `siginfo_t`) у контексті конкретного потоку.
